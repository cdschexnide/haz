# AFMAN 24-604 Attachment 19: Excepted Quantities and Limited Quantities Analysis

**Purpose:** Document how Excepted Quantities (A19.2) and Limited Quantities (A19.3) alter packaging, marking, and labeling requirements compared to standard hazardous materials shipments.

**Regulatory Reference:** AFMAN 24-604, Attachment 19 (9 October 2020)

---

## Executive Summary

| Provision | Packaging Impact | Marking Impact | Labeling Impact | Documentation Impact |
|-----------|-----------------|----------------|-----------------|---------------------|
| **Excepted Quantities** | Non-specification packaging allowed | Standard markings **EXEMPT** - use Figure A19.1 only | **EXEMPT** from all hazard labels | **EXEMPT** from SDDG |
| **Limited Quantities** | Non-specification packaging allowed | Standard markings **REQUIRED** (Attachment 14) | **REQUIRED** (Attachment 15) | **REQUIRED** (Attachment 17) |

**Key Insight:** Excepted Quantities provide broader exemptions from marking, labeling, and documentation requirements, while Limited Quantities only relax packaging specification requirements.

---

## Part 1: Excepted Quantities (A19.2)

### Overview

Per A19.2: *"Small quantities of hazardous materials are exempt from the specification packaging, marking, labeling, certification and compatibility requirements of this manual if the provisions of this paragraph are met."*

### 1.1 Materials NOT Eligible for Excepted Quantities

| Paragraph | Exclusion |
|-----------|-----------|
| A19.2.1.1 | Class 1 (all explosives) |
| A19.2.1.2 | Class 2.1 and 2.3; Division 2.2 with subsidiary hazard; aerosols |
| A19.2.1.3 | Class 4 PG I (primary or subsidiary) |
| A19.2.1.4 | Class 4.1 self-reactive material |
| A19.2.1.5 | Class 5 PG I (exception: in chemical kit or first aid kit) |
| A19.2.1.6 | Class 6.1 PG I by inhalation toxicity |
| A19.2.1.7 | Class 6.2 Infectious substances |
| A19.2.1.8 | Class 7 Radioactive (exception: excepted packages with associated risk) |
| A19.2.1.9 | Class 8 PG I, UN2803, UN2809 |
| A19.2.1.10 | Magnetized Material (Class 9), Carbon Dioxide Solid, Lithium Batteries |
| A19.2.1.11 | Hazardous material in devices (exception: temperature sensing devices) |
| A19.2.1.12 | Materials identified as "Cargo Aircraft Only" in Table A4.1 |

### 1.3 Packaging Requirements - ALTERED

Excepted quantities **DO NOT require UN specification packaging**. Instead:

| Component | Requirement | Reference |
|-----------|-------------|-----------|
| **Inner Packaging** | Plastic (min 0.2 mm), glass, earthenware, or metal | A19.2.3 |
| **Closures** | Secured with tape, self-shrink plastic, wire, or positive means (T-0) | A19.2.4 |
| **Liquids** | Must not completely fill at 55°C (130°F) (T-0) | A19.2.5 |
| **Intermediate Packaging** | Required - cushioning material; for liquids: absorbent for entire contents (T-0) | A19.2.6 |
| **Outer Packaging** | Strong, rigid (fiberboard, wood) | A19.2.7 |
| **Minimum Dimensions** | Two of three dimensions ≥ 100 mm (4 in); cylinders: height AND diameter ≥ 100 mm | A19.2.9 |

#### Package Testing (A19.2.12)

| Test | Requirement |
|------|-------------|
| **Drop Test** | 1.8 m (6 ft) onto solid, unyielding surface - 5 drops for rectangular, 3 for cylindrical |
| **Stack Test** | 24 hours with force equivalent to 3 m (10 ft) stack height |
| **Pass Criteria** | No breakage, leakage, or significant reduction in effectiveness |

### 1.4 Marking Requirements - EXEMPT

**Per A19.2.13.3:** *"Markings, labels, and documentation required by Attachments 14, 15, and 17 do NOT apply to excepted quantity shipments."*

#### Standard Markings NO LONGER REQUIRED:
- PSN and UN Number marking
- Consignee/shipper address
- Net quantity marking
- "Cargo Aircraft Only" marking
- Orientation arrows (for liquids)
- All other Attachment 14 markings

#### ONLY MARKING REQUIRED: Figure A19.1 Excepted Quantity Mark

| Specification | Requirement |
|--------------|-------------|
| **Size** | Minimum 100 mm x 100 mm (3.9 in x 3.9 in) |
| **Color** | Hatched border and symbol: red OR black |
| **Background** | White or contrasting |
| **Content** | Primary hazard class (*), shipper/consignee name (**) |
| **Durability** | Durable and clearly visible |

### 1.5 Labeling Requirements - EXEMPT

**All hazard labels required by Attachment 15 are NOT required for excepted quantities.**

Labels NO LONGER REQUIRED:
- Primary hazard label
- Subsidiary hazard labels
- "Cargo Aircraft Only" label
- Handling labels (orientation, etc.)
- Any other Attachment 15 labels

### 1.6 Documentation/Certification Requirements - EXEMPT

**Shipper's Declaration for Dangerous Goods (SDDG) is NOT required for excepted quantities.**

Documentation NO LONGER REQUIRED:
- SDDG form
- Emergency response information
- Shipper certification
- All other Attachment 17 documentation

### 1.7 Other Exemptions

| Standard Requirement | Status for Excepted Quantities |
|---------------------|-------------------------------|
| Compatibility requirements | EXEMPT |
| UN specification packaging | EXEMPT |
| Standard inner packaging tests | EXEMPT (use A19.2.12 tests instead) |

### 1.8 Multiple Materials Formula (A19.2.11)

When combining different hazardous materials in one outer packaging:

```
Q = n1/M1 + n2/M2 + n3/M3 + ...

Where:
- n = actual net quantity of each material
- M = maximum permitted per Table A19.1

Q must be ≤ 1.0
```

## Part 2: Limited Quantities (A19.3)

### Overview

Limited quantities allow shipment with **non-specification packaging** but **still require standard marking, labeling, and documentation**.

### 2.1 Materials NOT Eligible for Limited Quantities

| Paragraph | Exclusion |
|-----------|-----------|
| A19.3.1.1 | Materials forbidden in Table A4.1 |
| A19.3.1.2 | **All materials in Packing Group I** |
| A19.3.1.3 | Class 1 and Class 7 (except per 49 CFR 173.63) |
| A19.3.1.4 | Class 2.3 and Class 6.2 |
| A19.3.1.5 | Class 2.1 and 2.2 (except UN1950, UN2037, UN3478, UN3479) |
| A19.3.1.6 | Refrigerated liquefied gases |
| A19.3.1.7 | Class 4.1 self-reactive substances |
| A19.3.1.8 | Class 4.2 or any material with subsidiary 4.2 |
| A19.3.1.9 | Class 8: UN2794, UN2795, UN2803, UN2809, UN3028 |
| A19.3.1.10 | Class 9 (except specifically authorized in A19.3.2) |
| A19.3.1.11 | **Materials identified as "Cargo Aircraft Only" in Table A4.1** |

### 2.2 Materials PERMITTED for Limited Quantities (A19.3.2)

| Paragraph | Material |
|-----------|----------|
| A19.3.2.1 | Cartridges, small arms; Cartridges power device (Division 1.4S) per 49 CFR 173.63 |
| A19.3.2.2 | Aerosols UN1950/UN2037 (Class 2.1/2.2 without subsidiary); fuel cells UN3478/UN3479 |
| A19.3.2.3 | Class 2.2 gases without subsidiary (excluding refrigerated liquefied) |
| A19.3.2.4 | Class 3 (excluding PG I) |
| A19.3.2.5 | Class 4.1 (excluding PG I and self-reactive) |
| A19.3.2.6 | Class 4.3 solids only (excluding PG I) |
| A19.3.2.7 | Class 5.1 (excluding PG I) |
| A19.3.2.8 | Class 5.2 only in Polyester Resin Kit, Chemical Kit, or First Aid Kit |
| A19.3.2.9 | Class 6.1 (excluding PG I) |
| A19.3.2.10 | Class 8 (excluding PG I and specific UN numbers) |
| A19.3.2.11 | Specific Class 9: UN2071, UN1990, UN3077, UN3082, UN3316, UN1941, UN3334, UN3335 |

### 2.4 Packaging Requirements - ALTERED

| Requirement | Limited Quantities | Standard |
|-------------|-------------------|----------|
| **Packaging Type** | Combination packagings only | Per applicable attachment |
| **Single Packagings** | NOT permitted | Permitted where authorized |
| **Max Gross Weight** | 30 kg (66 lbs) | Per Table A4.1 |
| **UN Specification** | NOT required | REQUIRED |
| **General Requirements** | Must meet Attachment 3 | Must meet Attachment 3 |

#### Package Testing (A19.3.4)

| Test | Limited Quantities | Comparison |
|------|-------------------|------------|
| **Drop Test** | 1.2 m (4 ft) | Reduced from standard |
| **Stack Test** | 3 m (10 ft) for 24 hours | Same as standard |
| **Liquids** | Must meet A3.1.7 air-eligible requirements | Additional requirement |

### 2.5 Marking Requirements - STILL REQUIRED

**Per A19.3.5:** *"Mark, label, and certify limited quantity packages as required by Attachments 14, 15, and 17 of this manual."*

#### Markings STILL REQUIRED (per Attachment 14):
- PSN and UN Number
- Consignee name and address
- Net quantity per package
- "Cargo Aircraft Only" (if applicable - though CAO materials cannot use limited quantities)
- Orientation arrows (for liquids)
- All other applicable Attachment 14 markings

#### Marking EXEMPTION:
- **UN Specification Package Marking** - NOT required since non-specification packaging is allowed

### 2.6 Labeling Requirements - STILL REQUIRED

**All Attachment 15 labeling requirements apply to limited quantities.**

Labels STILL REQUIRED:
- Primary hazard label
- Subsidiary hazard labels
- Handling labels as applicable
- All other Attachment 15 labels

### 2.7 Documentation/Certification Requirements - STILL REQUIRED

**Shipper's Declaration for Dangerous Goods (SDDG) IS required for limited quantities.**

Documentation STILL REQUIRED:
- Complete SDDG form per Attachment 17
- Emergency response information
- Shipper certification
- All other Attachment 17 documentation

### 2.8 Passenger vs Cargo Aircraft

**Limited Quantities are ONLY for passenger aircraft-eligible materials.**

Per A19.3.1.11, materials marked "Cargo Aircraft Only" in Table A4.1 are NOT permitted in limited quantities.

## Part 4: Inspector Implementation Considerations

### Detecting Excepted Quantity Shipments

An inspector should identify an Excepted Quantity shipment by:
1. Presence of Figure A19.1 marking (100x100mm with hatched border and "E" symbol)
2. Absence of standard hazard labels
3. Absence of SDDG documentation
4. Small quantities within Table A19.1 limits

**Validation for Excepted Quantities:**
- Verify Figure A19.1 marking is present and properly formatted
- Verify material is eligible (not in exclusion list A19.2.1)
- Verify quantities are within Table A19.1 limits
- Verify packaging meets A19.2 requirements (not UN spec, but proper construction)

### Detecting Limited Quantity Shipments

A Limited Quantity shipment should have:
1. Standard SDDG documentation with "Limited Quantity" notation
2. Standard hazard labels per Attachment 15
3. Standard markings per Attachment 14
4. NO UN specification packaging marking (since non-spec packaging is allowed)
5. Quantities within Table A19.2 limits

**Validation for Limited Quantities:**
- Verify SDDG is present and complete
- Verify all standard labels are present
- Verify all standard markings are present (except UN spec marking)
- Verify material is eligible (PG II or III only, not CAO)
- Verify quantities within Table A19.2 limits
- Verify gross weight ≤ 30 kg

### Form 1015 Implications

| Field | Excepted Quantities | Limited Quantities |
|-------|--------------------|--------------------|
| Specification Packaging (54) | N/A - exempt | N/A - non-spec allowed |
| PSN/UN Marking (53) | N/A - exempt | Required - validate |
| Primary Hazard Label (69) | N/A - exempt | Required - validate |
| Subsidiary Labels (71) | N/A - exempt | Required - validate |
| Documentation (various) | N/A - exempt | Required - validate |

## Appendix A: Quick Reference Decision Tree

```
Is the shipment marked with Figure A19.1 (Excepted Quantity mark)?
├── YES → Excepted Quantity
│   ├── Verify material eligible per A19.2.1
│   ├── Verify quantities per Table A19.1
│   ├── NO hazard labels required
│   ├── NO SDDG required
│   └── NO standard markings required (only A19.1 mark)
│
└── NO → Check for Limited Quantity declaration on SDDG
    ├── YES → Limited Quantity
    │   ├── Verify material eligible per A19.3.1/A19.3.2
    │   ├── Verify PG II or III only
    │   ├── Verify NOT "Cargo Aircraft Only"
    │   ├── Verify quantities per Table A19.2
    │   ├── ALL hazard labels REQUIRED
    │   ├── ALL standard markings REQUIRED (except UN spec)
    │   └── SDDG REQUIRED
    │
    └── NO → Standard Shipment
        └── All normal requirements apply
```
