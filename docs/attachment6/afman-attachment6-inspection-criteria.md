## A6.2 - Aerosols

### A6.2.1 - Non-Toxic Aerosols

| Criteria | Requirement |
|----------|-------------|
| **Non-metal receptacle capacity** | ≤120 mL (4 fl oz) each |
| **Metal/plastic receptacle capacity** | ≤1 L (34 fl oz) each |
| **Maximum pressure at 55°C (130°F)** | ≤1245 kPa (180 psig) |
| **Burst test** | Must withstand 1.5x equilibrium pressure at 55°C without bursting |
| **Fill density** | Liquid content NOT completely fill at 55°C |
| **Package gross weight** | ≤30 kg (66 lbs) |

**Pressure-Based Container Selection:**
| Pressure at 55°C | Container Type |
|------------------|----------------|
| ≤970 kPa (140 psig) | Non-refillable metal/plastic ≤1L, or non-metal ≤120mL |
| 970-1105 kPa (140-160 psig) | DOT 2P, ICAO/IATA IP7, IP7A, IP7B |
| 1105-1245 kPa (160-180 psig) | DOT 2Q, ICAO/IATA IP7A, IP7B |

**Inspection Checklist:**
- [ ] Receptacle capacity within limits
- [ ] Pressure at 55°C does not exceed maximum
- [ ] Correct container type for pressure range
- [ ] Valves protected by cap or suitable means
- [ ] Gross weight ≤30 kg (66 lbs)
- [ ] Strong outer packaging meeting A19.3.4

### A6.2.2 - Other Aerosols (Including Toxic)

| Criteria | Requirement |
|----------|-------------|
| **Non-metal receptacle capacity** | ≤120 mL (4 fl oz) each |
| **Metal receptacle capacity** | ≤1 L (34 fl oz) each |
| **Maximum pressure at 55°C** | ≤1500 kPa (217 psig) |
| **For 1245-1500 kPa** | ICAO/IATA IP7B ONLY |

**Outer Packaging:** 4G, 4C1, 4C2, 4D, 4F, or 4H1/4H2 meeting PG II

### A6.2.3 - Biological/Medical Aerosols (Heat-Deteriorating)

| Criteria | Requirement |
|----------|-------------|
| **Inner receptacle capacity** | ≤575 mL (20 fl oz) |
| **Maximum pressure at 55°C** | ≤970 kPa (140 psig) |
| **Testing** | 1 per lot of 500 heated to 55°C equilibrium |
| **Package gross weight** | ≤30 kg (66 lbs) |

| Criteria | Requirement |
|----------|-------------|

| **Use restrictions** | Aircraft only, nonflammable gases ONLY |
| **Safety relief** | Frangible disc WITHOUT fusible metal backing |
| **Burst pressure rating** | ≤90% of minimum test pressure |
| **Packaging** | Strong outer packaging required |

### DOT-39 Cylinders

| Criteria | Requirement |
|----------|-------------|

|----------|-------------|
| Threads | Straight threads (except UN cylinders) |

### DOT-3AL Cylinders

| Criteria | Requirement |
|----------|-------------|
| **Flammable gases** | Cargo aircraft ONLY |

### A6.5.10 - Fluorine

### A6.5.12 - Diborane/Mixtures
